# results/

Working directory for training and evaluation outputs. Each run writes here
(configurable with `--output-dir`):

- `best_model.pt` — best checkpoint (by validation accuracy). Not committed (large).
- `config.json` — the exact `Config` used, so evaluation reproduces the split.
- `environment.json` — Python / PyTorch / Torchvision / CUDA / OS versions.
- `class_names.txt` — class order.
- `history.json`, `history.csv` — per-epoch loss, accuracy, learning rate, timing.
- `metrics.json` — for the unseen-location test set (and the seen-location set
  when one is carved): accuracy with a Wilson interval, balanced accuracy,
  macro precision/recall/F1 with a bootstrap interval on F1, top-2/top-3
  accuracy, expected calibration error, and a per-class report.
- `training_curves.png`, `confusion_matrix.png`, `error_analysis.png` — plots.

The contents are git-ignored (they are regenerated by the scripts). A committed
snapshot of the plots and metrics from the real infrared training run (Caltech
Camera Traps night-vision frames, ImageNet transfer learning) lives in
[`../docs/demo_results/`](../docs/demo_results/).

Note: a stale `results/samelocation/` from an earlier schema may still be present
locally; regenerate it if you want its numbers to line up with the current
`metrics.json` format.
